Made this repo public despite it being a largely "By me, for me" project in case anyone wants to judge my work, submit pull requests, or just generally see what I'm up to.

## About
A game engine written using MonoGame 3.8 and .NET 8. The goal is to do mostly everything from scratch as a learning experience (excluding largely tedious tasks like Serialization and Rendering), using MonoGame as a base and the advice from random game engine books I find.

Ideally the engine is scalable for large projects, supports modding assemblies and serialized game data, and has some basic multiplayer functionalities. This game engine is intended to be used for larger projects, and likely won't include an ECS. This game is primarily intended for Roguelike and 2D games, 3D is supported by MonoGame but not something I am interested in adding at the moment.

Goal is also 100% code coverage by tests.. we'll see how that works out.
